# Release QA report

Date: 2026-09-02  
Repository version: 0.2.0

## Scope

This report covers the recovered StageA MaxViT-Base/U-Net training source, the
maintained training/evaluation/inference package, and the ADS-B, height-prior,
optical-depth, longwave and statistical audit paths. Figure generation,
manuscript assembly, provider-controlled imagery and raw trajectory archives
are outside this repository.

## Unified test environment

The suite was run in Python 3.10.17 with NumPy 2.2.6, Pandas 2.2.3, SciPy
1.15.3, PyTorch 2.5.1, torchvision 0.20.1, timm 1.0.15,
segmentation-models-pytorch 0.5.0, Albumentations 1.4.24, OpenCV 4.11.0,
scikit-learn 1.7.2, XGBoost 3.1.2, xarray 2025.6.1, h5netcdf 1.6.4, h5py
3.14.0, rasterio 1.4.4, Shapely 2.1.2 and pyproj 3.7.1.

Result: **29/29 tests passed** across the standard suite and the two opt-in
integration checks for the external checkpoint and provider-controlled data
root. The only warnings were the two intentional warnings that trusted joblib
artifacts execute pickle payloads.

Additional checks:

- Ruff `E4,E7,E9,F` checks passed for `src`, `tests` and `tools`.
- Ruff formatting check passed for 35 maintained Python files.
- `compileall` passed for maintained code, tests, tools and legacy source.
- All 12 installed console entry points returned help successfully.

## Release conditions

The bundled LUT and two serialized height models were generated by the
authors, and their hashes and runtime compatibility were verified. The source
repository URL is recorded in `CITATION.cff`. The 337-MB checkpoint remains
outside Git history and should be placed in a versioned release or DOI-bearing
archive. ADS-B candidates remain geometric-consistency evidence rather than
unique flight attribution, and the longwave endpoint remains positive,
instantaneous and nighttime-only.
